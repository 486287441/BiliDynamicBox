# BiliNext - B站重构：全新首页、内容管理与自动追番

## 简短说明

重做 B 站首页与动态：自动追番抓取更新、聚合推荐与关注，一键想看、不想看。

## 详细说明

别再让推荐流替你决定下一个小时。

BiliNext 全面重构 B 站桌面体验：全新首页、推荐与关注内容、动态收件箱、收藏、历史、稍后再看和追番进度被整合进同一套界面。少一点干扰，多一点掌控。2.0 重点加入自动追番系统，让“这周更新到第几集”不再需要自己到处寻找。

打开 B 站，就能开始整理，而不是继续无止境地下滑。

核心功能：

• 清爽首页：统一浏览个性推荐、正在关注、热门视频与排行
• 动态收件箱：按日期整理关注 UP 主的新视频，今天更新了什么一目了然
• 想看 / 不想看：把值得看的内容加入稍后再看，不感兴趣的内容移入垃圾箱
• 自动追番抓取：输入番名即可自动搜索并挑选合适的 B 站合集，也可手动指定观看链接
• 自动同步进度：进入追番页面时自动从 Bangumi 抓取封面、总集数、放送状态、最新集数和更新时间
• 新集提醒：清楚标出当前更新进度与 NEW 状态，并显示下集预计播出日期
• 一键续看：保留你选择的 B 站合集或播放列表，查看更新后直接回到观看页面
• 收藏、历史、稍后再看：常用资料库直接进入，不必在复杂导航里来回寻找
• UP 主筛选：更轻松地管理自己真正想持续关注的创作者
• 可选 AI 分类：使用你自己的 DeepSeek API Key，将动态视频整理为知识或娱乐
• 可选“帮我读”：把视频链接交给配套的 Transcriber 项目处理，完成后可查看转写结果与推荐评分
• 深色 / 浅色模式：跟随你的观看习惯切换

BiliNext 不替你制造更多内容，只帮你更快找到真正想看的内容。

关于“帮我读”：

“帮我读”不能由本扩展单独完成。它必须配合作者的另一个 Transcriber 项目使用，并且需要在电脑上启动对应的本地服务（默认地址为 127.0.0.1:8765）。本扩展只负责把视频链接交给该项目并展示处理状态、转写结果与推荐评分；如果没有安装或没有启动 Transcriber，“帮我读”功能将不可用。其他首页整理、动态收件箱、追番、想看与不想看功能不受影响。

隐私与数据：

• “想看”“不想看”、垃圾箱、追番与筛选设置保存在浏览器本地
• B 站内容通过你当前的登录状态读取，扩展不会导出你的 Cookie
• AI 分类默认关闭；只有在你主动配置 DeepSeek API Key 并使用相关功能时，才会向 DeepSeek 发送视频标题用于分类
• 自动追番会向 Bangumi 查询公开的番组、剧集与播出日期信息，并可搜索 B 站公开内容来匹配观看合集
• “帮我读”仅在你主动点击时将视频链接交给电脑上正在运行的配套 Transcriber 项目

适合这些人：

• 想减少首页干扰与无意识刷视频
• 希望把 B 站当作学习、收藏和追番工具，而不只是推荐流
• 喜欢更克制、更统一的桌面端浏览体验
