动态页混有图文与视频，扫读成本高。BiliDynamicBox 用 收件箱式卡片流 只呈现视频动态，把每次打开变成「处理待办」：想看进稍后再看，不想看进垃圾箱且刷新不再出现。

用户价值

面向高频刷动态的用户，把「浏览」收窄为「决策」。

  • 按日分组，先处理今天再翻历史
  • 想看一键写入 B 站稍后再看，无需 API Key
  • 不想看仅隐藏当前条，不连带屏蔽 UP 其它内容

技术要点

Manifest V3 + Vue 3 + Pinia，UI 参考 BewlyBewly 扫读体验。

  • Content Script 替换动态页内容区
  • chrome.storage.local 持久化垃圾箱与计数
  • 同源 Cookie 调用公开接口，仓库不含密钥
