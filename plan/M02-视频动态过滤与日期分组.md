# M02-视频动态过滤与日期分组

技术依据：见 `plan/技术方案.md`。

## 目标

将动态原始数据转换为“仅视频动态 + 今天/昨天/日期分组”的可渲染数据结构。

## 实现范围

1. 设计 `DynamicItem` 与 `VideoDynamicCard` 类型。  
2. 实现 `filter-video.ts`，明确判定规则：仅保留视频动态。  
3. 实现 `group-by-date.ts`，输出固定分组顺序。  
4. 与 Pinia `inbox` store 打通，临时在 Vue 组件中输出分组标题与数量用于调试。

## 产出清单

- `src/domain/types.ts`
- `src/domain/filter-video.ts`
- `src/domain/group-by-date.ts`
- `src/store/inbox.ts`

## 验收标准

1. 图片动态与纯文字动态不进入结果列表。  
2. 结果分组包含：今天、昨天、具体日期（如 5月26日）。  
3. 同一条动态只出现一次，不跨组重复。  
4. 接口字段缺失时有兜底，不因单条脏数据中断全量渲染。

## 通过定义

在真实动态流里确认过滤与分组行为正确，进入 M03。
