# M05-连续5次不想看触发取关

技术依据：见 `plan/技术方案.md`。

## 目标

完成“同一 UP 连续 5 次不想看 -> 立即弹窗确认 -> 可执行取关”的完整链路。

## 实现范围

1. 在 `decision` Pinia store 维护 `upDislikeCounter` 累加逻辑。  
2. 达到阈值 5 时立即弹出确认框（本次会话即时触发）。  
3. 用户确认后调用取关接口；取消则仅保留计数。  
4. 成功/失败均给出 toast，失败不影响主页面继续使用。

## 产出清单

- `src/domain/decision-rules.ts`
- `src/store/decision.ts`
- `src/services/bilibili-api.ts`（取关接口分支）
- `src/services/toast.ts`（文案扩展）

## 验收标准

1. 同一 UP 连续点 5 次“不想看”必触发确认框。  
2. 取消取关不会破坏列表，也不会导致卡片回显异常。  
3. 确认取关后接口调用成功时提示明确，失败时可重试。  
4. 计数规则可解释、可回归测试（跨刷新保持一致）。

## 通过定义

该模块通过后，阶段 2 主功能闭环完成，可进入整体联调与收尾。
