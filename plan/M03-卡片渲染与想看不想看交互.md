# M03-卡片渲染与想看不想看交互

技术依据：见 `plan/技术方案.md`。

## 目标

实现 Bewly 风格卡片展示，以及每张卡片常驻“想看 / 不想看”按钮与即时反馈。

## 实现范围

1. 在 `VideoCard.vue` 渲染卡片字段：封面、标题、UP 主、发布时间。  
2. 卡片底部固定按钮区（常驻可见，不依赖 hover）。  
3. “想看”动作接入稍后再看接口并触发 toast。  
4. “不想看”动作通过 `decision` store 将卡片从当前视图移除，并交给存储层落库。

## 产出清单

- `src/components/InboxGroup.vue`
- `src/components/VideoCard.vue`
- `src/store/decision.ts`
- `src/services/bilibili-api.ts`
- `src/services/toast.ts`

## 验收标准

1. 卡片视觉层级符合 PRD：信息清楚、密度中等。  
2. 点击“想看”后有 toast 反馈，失败也有明确提示。  
3. 点击“不想看”后该卡片立即消失，不需刷新。  
4. 两个按钮始终可见，滚动/重渲染后不丢失事件绑定。
