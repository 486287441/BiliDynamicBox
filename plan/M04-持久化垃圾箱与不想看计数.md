# M04-持久化垃圾箱与不想看计数

技术依据：见 `plan/技术方案.md`。

## 目标

实现“不想看”记录持久化、垃圾箱恢复能力，以及 UP 维度的连续“不想看”计数。

## 实现范围

1. `storage.ts` 定义本地数据结构与读写 API。  
2. “不想看”写入 `dislikedDynamicIds` 与 `trashItems`。  
3. 刷新后仍可过滤已“不想看”动态。  
4. 在 `TopToolbar.vue` 接入垃圾箱入口，支持 `TrashModal.vue` 查看与恢复单条卡片。

## 产出清单

- `src/services/storage.ts`
- `src/store/trash.ts`
- `src/components/TopToolbar.vue`
- `src/components/TrashModal.vue`

## 验收标准

1. 已“不想看”卡片刷新页面后不再出现。  
2. 垃圾箱可查看历史项并执行恢复。  
3. 恢复后卡片可重新进入正常流（下次加载可见）。  
4. 数据迁移兼容旧版本空值与缺字段场景。

## 通过定义

持久化行为与垃圾箱交互稳定，进入 M05。
