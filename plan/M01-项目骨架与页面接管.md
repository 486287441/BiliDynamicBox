# M01-项目骨架与页面接管

技术依据：见 `plan/技术方案.md`。

## 目标

建立可运行的 MV3 扩展骨架，并在 `https://t.bilibili.com/` 稳定接管动态页内容区，为后续渲染模块提供容器。

## 实现范围

1. 创建 `manifest.json`、`vite.config.ts`、`vite.config.content.ts`、`tsup.config.ts` 等 Bewly 风格构建配置。  
2. Content Script 仅在 `t.bilibili.com` 页面执行。  
3. 实现页面就绪检测与容器挂载（避免重复注入），并挂载 Vue 根节点。  
4. 路由变化时自动重挂载（SPA 场景）。

## 产出清单

- `src/content/main.ts`
- `src/content/host-detect.ts`
- `src/content/page-replace.ts`
- `src/app/main.ts`
- `src/app/App.vue`
- `src/styles/base.scss`

## 验收标准

1. 打开非目标站点不注入任何 DOM。  
2. 打开 `https://t.bilibili.com/` 后，原动态内容区被插件容器替换。  
3. 前进/后退或站内切换后容器仍保持单实例可用。  
4. 控制台无重复初始化报错。

## 通过定义

手动验证以上 4 条全部满足，进入 M02。
